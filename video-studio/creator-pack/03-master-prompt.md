# Master Prompt — fill in and paste to Claude

Use this in a Claude Code session that has the `meine-claude-skills` repo attached.

```
Make a new story video with story-video-studio.

Genre: [What-if / Mystery / Thriller / Adventure / Drama]
Idea: [title from the Story Idea Library, or your own one-sentence idea]
Hook line (first 2 s): [ … ]
Visual symbol: [the one thing on screen that tells the story, e.g. a battery above every head]
Twist: [ … ]
Cast (all NEW): [name, age, look/outfit, personality] x 2–4
World (NEW place): [town name, 3–5 locations, time of day, weather]
Style: [rounded avatars / detailed block avatars]
Length: [90–130 s]
Ending question for the comments: [ … ]

Workflow: brainstorm/forge if the idea is thin → party-mode check of hook and twist →
show me the story in simple German before building → voices (af_jessica narrator) →
test stills every 1.5 s → fix → full render → 1-per-second review of the finished video →
thumbnail with big text → captions, title, hashtags, pinned comment.
Rules: free tools only, English video, explanations in simple German, no copying of other creators.
```

## Quick fixes for common problems
| Problem | Fix |
|---|---|
| Faces too dark | add the camera-side front fill light; never film into the sun |
| Characters cut off at the edges | portrait frame is narrow: keep two people within ~1.5 units, or pull the camera back |
| Camera inside a head / wall | use `CU()` close-ups; check stills every 1.5 s |
| Story feels slow | cut a shot every 1.5–2.5 s; shorten narrator lines; speed 1.08 |
| Captions hidden by TikTok buttons | keep text above y 1600 and left of x 960 |
| Everyone looks the same | give every crowd member an explicit outfit, hair, accessory and skin tone |
